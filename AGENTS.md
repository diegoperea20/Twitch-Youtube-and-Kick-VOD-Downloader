# downloadvods — Project Guide for AI Agents

## Overview

Multi-platform VOD downloader for **Twitch**, **Kick**, and **YouTube**. Provides a Streamlit GUI (`app.py`) and a CLI tool (`download_vod.py`). Downloads videos via `yt-dlp`, processes with `ffmpeg`, and outputs H.264 MP4 files.

## Tech Stack

- **Python 3.11+**
- **`yt-dlp`** — video extraction & downloading
- **`ffmpeg`** — encoding, transcoding, trimming
- **`streamlit`** — GUI (used only by `app.py`)
- **`uv`** — dependency management & execution

## Available Commands

```powershell
# GUI (Streamlit)
uv run streamlit run app.py

# CLI
uv run python download_vod.py --url <URL> [options]
```

## CLI Reference — `download_vod.py`

| Argument | Required | Default | Description |
|---|---|---|---|
| `--url` | Yes | — | Video URL (Twitch, Kick, YouTube) |
| `--quality` | No | `best` | Quality like `1080p60`, `720p`. Invalid → best |
| `--start` | No | `0` | Start time (seconds or `HH:MM:SS`) |
| `--end` | No | `0` | End time (`0` = full video) |
| `--no-gpu` | No | off | Disable GPU acceleration |
| `--output` / `-o` | No | `.` | Output file (`.mp4`) or directory |
| `--browser` | No | — | Browser for YouTube cookies (`chrome`, `firefox`, etc.) |
| `--quiet` / `-q` | No | off | Suppress progress output |

> **PowerShell note:** URLs containing `&` (e.g. YouTube with `&list=...`) **must** be enclosed in double quotes (`"url"`). PowerShell treats unquoted `&` as a special character.

### Examples

```powershell
uv run python download_vod.py --url https://www.twitch.tv/videos/123456789
uv run python download_vod.py --url "https://youtube.com/watch?v=xxxx&list=...&start_radio=1" --quality 1080p --start 00:05:00 --end 00:10:00
uv run python download_vod.py --url https://kick.com/video/xxx --output D:\videos --no-gpu
uv run python download_vod.py --url "https://youtube.com/watch?v=xxxx" --browser chrome
```

## Code Conventions

### Imports
Standard library first, then third-party, then local. One import group per section.

### Naming
- `snake_case` for functions and variables
- `UPPER_CASE` for constants
- Private helpers prefixed with `_`

### Output paths
All status/progress output goes to **stderr**. Only the final file path goes to **stdout**. This allows capturing the output path:
```powershell
$path = uv run python download_vod.py --url <URL> --quiet 2>$null
```

### Error handling
Use `sys.exit(1)` on failure. Error messages go to stderr. The CLI never raises unhandled exceptions.

### GPU detection
`check_gpu_encoder()` runs `ffmpeg -encoders` and parses output for known encoders:
- `h264_nvenc` (NVIDIA)
- `h264_amf` (AMD)
- `h264_vaapi` / `h264_qsv` (Intel)

## File Naming Convention

Output files use the format: `{sanitized_title}_{HH-MM-SS}_{HH-MM-SS}.mp4`

## Notes for AI Agents

- **Do not modify `app.py`** unless explicitly asked. It is the Streamlit GUI and works independently.
- The CLI (`download_vod.py`) is a self-contained file with no imports from `app.py`. Changes to one do not affect the other.
- YouTube downloads often require browser cookies. Use `--browser chrome` (or firefox, edge) for authenticated access.
- The project root is `C:\Users\user\Documents\downloadvods`. Use absolute paths when specifying `--output` outside this directory.
- All commands should be run with `uv run python` to use the project's virtual environment.
